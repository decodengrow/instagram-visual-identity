# Instagram Visual Identity — скилл для Claude

Скилл для Claude Code и Claude.ai, который проводит обратный инжиниринг визуальных референсов и строит из них масштабируемую систему визуальной идентичности бренда для Instagram.

## Что делает

Работает в 10 этапов:

1. Анализ каждого референса: композиция, типографика, цвет, графический язык, изображения, информационная архитектура, семиотика
2. Закономерности между референсами: сравнительная матрица, визуальная ДНК, противоречия, уровни достоверности
3. Три разных креативных направления и выбор лучшего
4. Архитектура идентичности: цвет (HEX), типографика, сетки, фирменные элементы, правила согласованности
5. Архитектуры каруселей A–G, обложки, внутренние и финальные слайды
6. Форматы за пределами каруселей: одиночные посты, Reels, Stories, серии
7. Преобразование контента в дизайн
8. Производственные спецификации слайдов с координатами
9. Контроль качества по 12 критериям
10. Итоговая выдача из 15 разделов и мастер-промпт для будущих публикаций

## Установка

**Claude Code:**

```bash
git clone https://github.com/decodengrow/instagram-visual-identity ~/.claude/skills/instagram-visual-identity
```

**Claude.ai:** скачайте репозиторий как ZIP и загрузите его в Settings → Capabilities → Skills.

## Использование

Пришлите референсы (скриншоты постов, мудборд) и коротко опишите бренд, например: «Разбери эти референсы и сделай визуальную систему для Instagram». Скилл запустится сам, или вызовите его явно: `/instagram-visual-identity`.
